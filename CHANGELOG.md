# Changelog

Todos los cambios relevantes de **skills-404-complement** se documentan en este archivo.
El proyecto sigue [Keep a Changelog](https://keepachangelog.com/es-ES/1.1.0/) y [Semantic Versioning](https://semver.org/lang/es/).

## Reglas de Versionado para Skills

- **MAJOR (`X.0.0`):** Cambia el contrato de secciones, criterios bloqueantes o flujo incompatible de una skill.
- **MINOR (`1.X.0`):** Añade nuevas skills, referencias, ejemplos o reglas compatibles hacia atrás.
- **PATCH (`1.0.X`):** Correcciones menores de redacción, enlaces o ejemplos sin alterar reglas.

## [1.0.0] - 2026-11-23

### Added
- `clean-code` (`1.0.0`): Skill de auditoría, organización y refactorización segura (Martin, Fowler, Ousterhout, Hunt & Thomas, Metz).
- `hexagonal-architecture` (`1.0.0`): Skill de Arquitectura Hexagonal (*Ports & Adapters*), SOLID y *Composition Root* (Cockburn, Martin, Vernon, Seemann).
- `qa-validator` (`1.0.0`): Skill transversal Quality Gate de comportamiento, eficiencia FE/BE/Datos, seguridad OWASP, resiliencia y OpenTelemetry.
- `ui-engineering-rules` (`1.0.0`): Skill de invariantes universales UI y semántica DOM (Apple HIG, Material Design 3, Vercel, Refactoring UI, WCAG 2.2 AA).
- `_TEMPLATE/SKILL_TEMPLATE.md` (`1.0.0`): Plantilla base con contrato uniforme (LSP) de 6 secciones H2.
- Estándares internos de calidad: 0 emojis, 0 `any` en código limpio, comentarios breves solo de *por qué* y referencias segregadas por SRP/ISP.
